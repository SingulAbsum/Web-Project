This project demonstrates core php web functionalities while also working on basic frontend languages such as :html,css and javascript.
Developed a PHP-based news and article web service using SQL, designed to demonstrate CRUD operations, dynamic content management, and structured backend architecture, with emphasis on data handling and application logic.
To run the project ,you should download xamp server and put the projects folder on the htdocs folder of xamp and also import the sql test file for mock data in phpmyadmin.
